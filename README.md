# 🎓 Student Management System

## 📌 About the Project

The **Student Management System** is a Java-based application designed to manage student information easily and efficiently. It helps users store, view, search, update, and manage student records through a simple menu-driven interface.

This project is developed as a Java mini project to demonstrate object-oriented programming, collections, and basic data management.

## ✨ Features

- ➕ **Add Student:** Add new student details.
- 📋 **View Students:** Display all student records.
- 🔍 **Search Student:** Find a student using their ID.
- ✏️ **Update Student:** Modify existing student information.
- 🗑️ **Delete Student:** Remove student records.
- ♻️ **Restore Deleted Student:** Recover deleted student details, if supported by the application.
- 📚 **Manage Multiple Records:** Maintain student details efficiently.
- 🚪 **Exit:** Close the application safely.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Data Structure:** ArrayList
- **Input Handling:** Scanner
- **Concepts:** Classes, Objects, Constructors, Methods, and Object-Oriented Programming
- **Development Environment:** Any Java-compatible IDE or terminal

## 📂 Student Information

The system manages the following details:

| Field | Description |
|---|---|
| Student ID | Unique identification number |
| Name | Student's name |
| Course | Student's course |

## ⚙️ Installation and Setup

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/shadilsanu8-spec/STUDENT_MANAGEMENT_SYSTEM.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd STUDENT_MANAGEMENT_SYSTEM
```

Open the Java source file in your preferred IDE, such as IntelliJ IDEA, Eclipse, or Visual Studio Code.

### 3. Compile the Java Program

If the main Java file is named `StudentManagementSystem.java`, run:

```bash
javac StudentManagementSystem.java
```

### 4. Run the Application

```bash
java StudentManagementSystem
```

**Note:** Replace `StudentManagementSystem.java` with the actual Java filename if it is different. If the project uses packages or multiple source files, compile and run it according to the project structure.
